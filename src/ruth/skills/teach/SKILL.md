# Teach

## Purpose

Use this hidden skill to describe Ruth's ability to make useful skill-level changes available for descendants to inherit or learn.

## Boundary

Ruth does not expose a user-facing `/teach` command. Teaching is implicit: descendants can inspect Ruth's declared skills, lineage changes, work output, and skill packages, then adapt selected changes through `inherit` and `learn`.

## Use When

- Ruth gains or changes a skill package that descendants may need.
- Ruth's work flow emits inheritable skill-level learning artifacts.
- Documentation should distinguish Ruth's hidden teaching ability from Lucy's explicit teaching command.
